## PRISM//BREACH — Neon Protocol

A stylized 3D tactical FPS built with Three.js. No build step — open the page and deploy.

**Mission:** eliminate 8 rogue sentinels in the Glasshouse before the extraction window closes.

- **Weapons** — VANDAL (one-tap rifle), GHOST (precise sidearm), SPECTRE (run-and-gun SMG). Each has its own ammo, cadence and handling.
- **Powers** — `E` Phase Shift dash, `C` Sonar Pulse through-wall reveal, `Q` **Prismatic Breach** (time fracture + expanding prism shockwave).
- **Enemies** — Sentinel (armoured burst), Stalker (fast flanker), Warden (charged long-range shot), Weaver (blinking prismancer).
- **Controls** — WASD move, Shift sprint, Space jump, Left click fire, Right click aim, `1/2/3` swap weapons, `R` reload, `Esc` pause.
- **Touch** — responsive portrait/landscape layout with a virtual stick, swipe-to-aim, fire/jump/dash/scan/ult buttons and weapon cycle.

Assumption: "Valorant-inspired" means hero-shooter powers, neon tactical presentation and a training-sim elimination objective, not a literal clone of Valorant's maps or agents.
